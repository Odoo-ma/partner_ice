# Partner ICE

Ce module Odoo ajoute le champ **ICE** (Identifiant Commun d’Entreprise) dans les partenaires et sur les factures.

---

## 📌 Fonctionnalités
- Ajout d’un champ **ICE** dans les partenaires (`res.partner`)
- Affichage de l’ICE sur les factures clients et fournisseurs
- Intégration dans les vues de formulaire et rapports PDF

## ⚙️ Installation
1. Copier le dossier du module dans ton répertoire `addons`.
2. Mettre à jour la liste des modules dans Odoo.
3. Installer **Partner ICE** depuis Apps.
